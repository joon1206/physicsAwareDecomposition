# Compact raw timing evidence

The repository stores this archive as 21 checksum-verified volumes named `timing_evidence.tar.gz.part000` onward. From `research/physicsAwareDecomposition`, run `bash actionStudy/scripts/run.sh assembleTimingEvidence.py` to verify each volume and reconstruct the original archive. `parts.json` and `manifest.json` record the unchanged archive SHA256. The full assembled file is ignored by Git to avoid a large individual Git object.

`timing_evidence.tar.gz` preserves cost manifests, rank timing CSVs, canonical cell IDs, solver logs and campaign/build logs. `manifest.json` records every member hash and archive hash. Full transient fields are retained at `/home/joon1206/research/ForFun/research/physicsAwareDecomposition/actionStudy/data/raw` and ignored by Git. State-preserving physical-endpoint experiments are used. Rejected interior-write/native-restart epochs, the original repeated-cyclic utility failure, partial runs before segment retention, and the stopped archive-overlap attempt remain locally preserved and are excluded. The final randomized live collection uses finalized code and retains every segment. Source checksums and build environment are in `docs/`.
